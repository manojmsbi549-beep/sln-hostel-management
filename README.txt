SLN Boys Hostel Management PWA

This is an installable Progressive Web App package. It must be served from an HTTPS website (or localhost) for Android Chrome to offer Install app and for offline caching to work. Opening index.html directly as a file will run the app but will not enable PWA installation/offline service worker.

Deploy all files in this folder to the same directory on an HTTPS static host. Open that HTTPS URL on your Android phone in Chrome, tap the three-dot menu, then Install app or Add to Home screen. Open the installed app once online; it can then load offline.

Data is stored locally in the browser on the phone. Export backups regularly. Clearing browser storage or uninstalling may remove data. This starter version has no cloud sync or login.


Fee reminder feature: the Reminders tab lists guests with unpaid monthly fees and opens WhatsApp with a Telugu message. The app records up to 3 reminder attempts per guest per month and stops offering reminders when that month's balance is paid. The management user must review and press Send in WhatsApp. Automatic scheduled sending while the app is closed is not available in this offline starter package; that requires an online backend and an approved WhatsApp Business/SMS provider.
